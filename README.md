# Photo Site 2（フォトサイト2） [3周目]

CODEJUMP 入門編の「フォトサイト2／1カラム」課題として制作しているWebサイトです。（基礎固めの3周目）

## 概要

「友人が2冊目の写真集を出版することになった」という架空の案件設定のもと、紹介用のWebページ（1ページ）を制作しています。
1冊目のレイアウトからデザインやコンテンツ幅を変更し、より実践的なレスポンシブ対応を行っています。

CODEJUMPの課題を通して、HTML・CSSの基礎構造やレイアウト設計、レスポンシブ対応について学習しています。

## コーディング仕様・学習内容

- **コンテンツ幅**: メインビジュアル 1000px / 中のコンテンツ 800px
- **INDEX セクション**:
  - グレー背景・枠線の配置
  - 画像の2列横並び配置
- **DETAIL セクション**:
  - 出版情報とテキストの横並び配置（間に罫線）
- **レスポンシブ対応**:
  - ブレークポイント 1024px
  - INDEX: 画像4枚を1列（縦積み）に配置
  - DETAIL: 出版情報とテキストを縦並びに配置（間に罫線）
- **Git / GitHub**: バージョン管理

## 使用技術

- HTML5
- CSS3
- Git / GitHub
